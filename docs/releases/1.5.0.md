## Changes

- Added optional Dynamic selection: tap to smoke your last-used available item, hold to open the wheel, and adjust the hold delay with a slider (0.25 seconds by default).
- The last-used item is remembered across restarts; first use or an unavailable remembered item falls back to the first available item.
- During active free smoking in Dynamic mode, tapping the hotkey stops the session; holding it leaves the session running without opening the wheel.
- Classic remains the default selection mode and keeps its existing behavior.

## Choose one download

- **Nivalis.Cigarette-1.5.0.zip** — standalone version for normal play.
- **Nivalis.Cigarette-1.5.0-API.zip** — use when another mod requires Cigarette integration.

Install one variant at a time. Extract it into the game directory and replace the previous DLLs. Both archives include Mod Companion. Existing configuration, including a customized hold duration, is preserved.
