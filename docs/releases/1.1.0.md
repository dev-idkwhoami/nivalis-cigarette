Choose a cigarette, joint, or inhalant mask from the new radial menu when left-clicking a supported railing.

- Added a tapered joint model and configurable after-effects: animated RGB separation, slow blur, camera tilt, and world-placed singer hallucinations. Effects start after smoking; consuming more earns more effect time.
- Added the city inhalant mask with a dedicated hand pose, bundled bubbling inhale audio, and audio-only exhaling. Its after-effect slows the world and player movement to 50% by default, with duration earned from inhaling.
- Added separate session-duration settings for cigarettes, joints, and masks. Mask inhale volume defaults to 0.125; effect strength and duration are configurable in `BepInEx/config/cigarette.cfg`.
- Added colored voxel-style menu icons and support for three additional Seaside Boardwalk railings.
- Added a separate railing development tool in the source repository for capturing and testing unsupported surfaces. It is excluded from the release download.

**Installation:** extract the ZIP into the game directory, replacing `BepInEx/plugins/Nivalis.Cigarette.dll`, then restart the game. Audio and icons are embedded; no separate asset installation is needed. Existing configuration values are preserved and missing settings are added on launch.
