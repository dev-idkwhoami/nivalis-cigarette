## Changes

- Added an optional API so cooperating mods can react to smoking, control smoking items, and manage effects.
- Added separate standalone and API-enabled downloads; normal smoking features are available in both.
- Fixed railing alignment when standing close, clicking the far edge, or playing at high frame rates.

## Choose one download

- **Nivalis.Cigarette-1.3.0.zip** — standalone version for normal play.
- **Nivalis.Cigarette-1.3.0-API.zip** — use this version when another mod requires Cigarette integration.

Install one variant at a time. Extract it into the game directory and replace the previous Cigarette DLL. Your existing configuration is preserved. The development test mod is not included in either archive.

Mod authors: see the [API documentation](https://github.com/dev-idkwhoami/nivalis-cigarette/blob/1.3.0/API.md).
