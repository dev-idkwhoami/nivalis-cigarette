## Changes

- Mod Companion is now included for the smoking hotkey and in-game settings.
- Smoke while standing or walking with a new chest-height hand pose and gentle movement sway.
- Press X to start or stop smoking anywhere on foot; rebind the key in Mod Companion.
- Keep smoking as you start and stop walking. Interacting with an object ends the session.
- Choose whether sprinting is allowed while smoking; disabled by default.
- Walking uses slower free-arm animation, while sprinting retains normal animation speed. Player movement speed is unchanged.
- Enable cigarettes, cannabis and inhalant masks individually under Mod Companion → Cigarette → General.
- Start immediately when only one item is available, using either the hotkey or a railing.
- Added the cigarette icon to Mod Companion.
- Added read-only API queries for user item preferences. User-disabled items cannot be enabled by another mod's API calls.

## Choose one download

- **Nivalis.Cigarette-1.4.0.zip** — standalone version for normal play.
- **Nivalis.Cigarette-1.4.0-API.zip** — use this version when another mod requires Cigarette integration; includes the updated API library.

Install one variant at a time. Extract it into the game directory and replace the previous Cigarette DLLs. Your existing configuration is preserved. Both archives include the shared Mod Companion DLL; allow it to replace the existing copy. Archives contain only the Cigarette DLLs and Mod Companion DLL, with no documentation or development tools.

Mod authors: see the [API documentation](https://github.com/dev-idkwhoami/nivalis-cigarette/blob/1.4.0/API.md) for contract 2 and the read-only preference queries.
