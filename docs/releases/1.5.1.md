## Changes

- Fixed hand placement failing on supported sloped railings around 20 degrees.
- Improved diagnostics for failed railing hand contacts.

## Known issue

- Some winter railings near snow still fail hand placement when another collider obstructs the hand probes.

## Choose one download

- **Nivalis.Cigarette-1.5.1.zip** — standalone version for normal play.
- **Nivalis.Cigarette-1.5.1-API.zip** — use when another mod requires Cigarette integration.

Install one variant at a time. Extract it into the game directory and replace the previous DLLs. Both archives include Mod Companion; existing settings are preserved.
